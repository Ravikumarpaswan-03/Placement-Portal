This walkthrough provides a file-by-file breakdown, explaining the code structure, 
key functions, libraries, API routes, and database schemas implemented across the 
entire OJT Progress Tracker (Week 1) and Placement Cell Portal (Weeks 2-4).

--------------------------------------------------------------------------------
1. PROJECT ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
The system is built as a decoupled full-stack application (MERN-adjacent, using 
Vanilla HTML/CSS/JS for high performance on the frontend instead of React):
- Frontend (Client): Light HTML templates styled with transparent, glassmorphic 
  dark-mode CSS. pure JavaScript `fetch()` calls handle JSON exchanges.
- Backend (Server): Node.js web server running Express.js for routing, Multer for 
  resume storage, and JWT token validation.
- Database: MongoDB for persistent document store, mapped using Mongoose ODM schemas.


--------------------------------------------------------------------------------
2. DATABASE SCHEMAS (backend/models/)
--------------------------------------------------------------------------------

1. User.js
- Purpose: Handles core login credentials.
- Fields:
  * name (String, Required)
  * email (String, Required, Unique)
  * passwordHash (String, Required)
  * role (Enum: ["student", "company", "mentor", "admin"])
  * canCreateAdmin (Boolean, default: false)

2. Student.js
- Purpose: Stores student details, skills, and resumes.
- Fields:
  * userId (ObjectId referencing User)
  * name (String)
  * email (String)
  * skills (Array of Strings)
  * cgpa (Number)
  * resumeUrl / resumeLink (String)
- Pre-save Hook: Matches resumeLink to resumeUrl if only one is updated, ensuring 
  data uniformity.

3. Job.js
- Purpose: Defines recruiters' job openings.
- Fields:
  * title, companyName, companyId, location, salary, package (Strings)
  * skills (Array of Strings)
  * minCgpa (Number, default 0)
  * deadline (Date)
  * description (String)

4. Application.js
- Purpose: Connects students to jobs in the recruitment pipeline.
- Fields:
  * studentId, jobId, studentName, jobTitle (Strings)
  * status (Enum: ["Applied", "Shortlisted", "Selected", "Rejected"])
  * appliedAt (Date)

5. LoginAttempt.js
- Purpose: Audit database tracking login safety.
- Fields:
  * email (String)
  * status (Enum: ["Success", "Failed"])
  * ipAddress (String)
  * reason (String)
  * timestamp (Date)


--------------------------------------------------------------------------------
3. BACKEND CONFIGURATION & MIDDLEWARES (backend/)
--------------------------------------------------------------------------------

1. server.js (Main Entry)
- Purpose: Boots up the server, connects database, applies middlewares, and routes.
- Middlewares Used:
  * cors: Handles CORS, permitting access from frontend port 5500.
  * express.json(): Parses incoming JSON bodies.
  * express.static: Serves static frontend files and uploads.
- Key Lines:
  * app.use("/api/auth", authRoutes) - Registers auth APIs.
  * app.use("/api/students", studentRoutes) - Registers student profile APIs.
  * app.use("/api/jobs", jobRoutes) - Registers jobs CRUD.

2. config/db.js (Database Connector)
- Key Function: connectDB() connects to MongoDB using mongoose.connect(process.env.MONGO_URI).

3. config/multerConfig.js (PDF File Upload)
- Key Library: multer stores uploaded files.
- Configurations:
  * Restricts file types to .pdf via fileFilter.
  * Sets file size ceiling to 5MB.
  * Generates unique filenames: resume-<timestamp>-<random>.pdf to avoid overwrites.

4. middlewares/authMiddleware.js (JWT Parser)
- Key Function: Checks req.header("Authorization") for Bearer <token>. Decodes the 
  payload using jwt.verify(token, process.env.JWT_SECRET) and attaches user info 
  to req.user.

5. middlewares/validateIdMiddleware.js (ID Check)
- Key Function: Validates :id parameters using mongoose.Types.ObjectId.isValid(). 
  Prevents system crashes from invalid query lengths.


--------------------------------------------------------------------------------
4. BACKEND CONTROLLERS (backend/controllers/)
--------------------------------------------------------------------------------

1. authController.js (Authentication Core)
- Key Functions:
  * register(req, res):
    - Calls validateEmail(email) (utils module checking domain MX records).
    - Enforces max 3 accounts using the same email address.
    - Compares new password against existing accounts to prevent duplicate reuse.
    - Encrypts password using bcrypt.hash(password, 10) and creates a user record.
  * login(req, res):
    - Finds user account by email.
    - Compares password using bcrypt.compare(password, user.passwordHash).
    - Log attempts to LoginAttempt schema (email, IP, outcome).
    - If valid, issues JWT token: jwt.sign({ id: user._id, role: user.role }).

2. studentController.js (Student Details)
- Key Functions:
  * getStudentProfile(req, res): Returns student profile matching user token.
  * updateStudentProfile(req, res): Updates name, skills list, and CGPA parameters.
  * uploadResume(req, res): Saves uploaded PDF file path onto student profile resumeUrl.

3. jobController.js (Job CRUD)
- Key Functions:
  * getJobs(req, res): Queries job collection, supporting location/search filters.
  * createJob(req, res): Recruiter/Admin posts job descriptions and requirements.
  * updateJob(req, res): Updates salary/package or cutoff parameters.
  * deleteJob(req, res): Removes job posting from database.

4. applicationController.js (Applications Pipeline)
- Key Functions:
  * getApplications(req, res): Fetches applications (students see only their own; 
    staff see complete directories).
  * createApplication(req, res): Inserts new candidate application.
  * updateApplication(req, res): Updates status tag (Applied, Shortlisted, Selected, Rejected).

5. analyticsController.js (Statistics Aggregates)
- Key Function: getDashboardData(req, res) uses MongoDB aggregations to return count 
  of selected/shortlisted/applied logs and user registration distributions.


--------------------------------------------------------------------------------
5. FRONTEND VIEWS & JAVASCRIPT ACTIONS (frontend/)
--------------------------------------------------------------------------------

1. index.html & js/index.js (Portal Gate)
- Purpose: Entry portal showing Login / Registration options.
- Key Functions:
  * handleLogin(e): Sends login request to backend, saves JWT token and role in 
    LocalStorage, and redirects user to their dashboard page.
  * togglePasswordVisibility(): Toggles input box type from password to text to 
    show/hide letters.

2. pages/student-dashboard.html & js/student-dashboard.js
- Purpose: Renders student analytics charts, personal metrics, and recommendations.
- Key Functions:
  * loadStudentDashboard():
    - Fetches statistical aggregates to initialize a Chart.js Doughnut chart.
    - Fetches Student Profile, Jobs list, and Applications concurrently.
    - Skill Matching Recommendation (Slide 9): Calculates matching percentages:
      Match Score = (CommonSkills / JobSkills) * 100
    - Renders the top 3 recommended job matches with matching skills highlighted 
      and eligibility cutoffs checked dynamically.

3. pages/jobs.html & js/job.js (Recruitment Center)
- Purpose: Search, filter, and apply for jobs.
- Key Functions:
  * filterJobs():
    - Universal Search: Checks search query against job title, company, skills, 
      or application status.
    - Filters: Filters jobs in real-time by Location, Required Skill, Minimum Package 
      (LPA), and Deadline Status.
    - Sorting: Sorts list dynamically by Newest, Highest Package, Most Relevant 
      (match score), or Status Priority.
  * renderJobList(jobs): Generates card layouts with CGPA eligibility checks and 
    matching score percentage badges.

4. pages/student.html & js/student.js (Profile Setup)
- Purpose: Page to update skills list, CGPA, and upload resumes.
- Key Functions:
  * handleProfileUpdate(e): Updates student details in DB.
  * handleResumeUpload(e): Uploads PDF resume file using FormData object via Multer route.

5. pages/admin-dashboard.html & js/admin-dashboard.js (Admin Tools)
- Purpose: Centralized credentials editor, password resets, and auditing database 
  monitoring.
- Key Functions:
  * loadLoginAttempts(): Renders the login security audit logs.
  * handleAdminResetUserPasswordSubmit(): Resets target user credentials. The new 
    password is set to match their respective email ID.

6. pages/company-dashboard.html & js/company-dashboard.js (Recruiter)
- Purpose: Allows recruiters to post/update listings and see candidate lists.

7. pages/mentor-dashboard.html & js/mentor-dashboard.js (Mentoring)
- Purpose: Renders student logs and directory list readouts.


--------------------------------------------------------------------------------
6. OJT TRACKER MODULE (OJT-PROGRESS-TRACKER/)
--------------------------------------------------------------------------------

1. dashboard.html & dashboard.css
- Purpose: Independent page layout for tracking daily internship tasks.

2. dashboard.js (Client-Side State Engine)
- Key Functions:
  * addTask(title, desc): Saves tasks into LocalStorage.
  * toggleTaskStatus(taskId): Updates state (Pending, In Progress, Completed).
  * updateProgressBar(): Re-calculates task completion percentage:
    Completion = (CompletedTasks / TotalTasks) * 100


--------------------------------------------------------------------------------
7. SETUP AND RUNNING INSTRUCTIONS
--------------------------------------------------------------------------------
1. MongoDB: Start your database on local port 27017.
2. Server: Open backend/ in terminal, install dependencies, and start Node:
   cd backend
   npm install
   npm run dev
3. Frontend: Open frontend/index.html in VS Code, right-click and choose 
   "Open with Live Server" (runs on port 5500).
